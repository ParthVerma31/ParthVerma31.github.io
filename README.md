# 🎮 Cube

My first playable Unity game project, created while learning game development.

## 🕹️ About

Cube is a simple Unity-based game developed using **Unity** and **C#**.

This project helped me learn the fundamentals of:
- Player movement
- Game mechanics
- Level design
- Unity scenes
- C# scripting

## ✨ Features

- 🎮 Multiple levels
- 🧩 Simple gameplay mechanics
- 🕹️ Keyboard controls
- 🎯 In-game objectives
- 🖥️ Windows x64 build

## 🎮 Controls

- Use the keyboard to control the player.
- Follow the instructions shown in the game.
